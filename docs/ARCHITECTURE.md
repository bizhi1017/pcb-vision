# 数据链路与功能边界

1. 双IMX415通过各自采集链路进入FPGA；预处理模式在完整帧边界锁存。
2. FPGA将完整源帧组织成协议包。lossless逐字节重建；lossy6对RAW10保留高6位、对灰度8位保留高5位，再按协议2封装。包长、CRC、序号和通道标签用于接收校验。
3. PCIe SGDMA将压缩包交给RK。板端解码原始数据、颜色转换、生成高清图；缺陷推理与视频分开调度，实际推理FPS独立于预览FPS。
4. 网络预览优先使用RK MPP JPEG，缺SDK/失败可能回退CPU；完整无损路径使用PNG或PCZ1。预算Mbps/路、自适应码率、发送FPS和尺寸只控制网络预览，不改变检测源分辨率。
5. Qt显示原图和检测元数据；手机浏览器按所选通道订阅，支持检测/HDMI/测量/截图控制及首次缺陷铃声。HDMI由板端显示进程负责。
6. 尺寸仅测PCB材料外框，A/B各自标定；相机位置、焦距、高度或板厚变化后需检查/重标定。原型结果不宣称工业计量精度。

缺件绿色、划痕黄色、污渍红色；无检测/过期状态与“无异常”区分。截图SD和当前客户端存储可单独选择。
