# ===================== 当前：三分类（missing / stain / scratch）2026-10-25 定 =====================
#   演示板：HU-149A（PH1A90SEG324 + RK3576J）
#       id 0 = missing  缺件   —— 该有元件的位置只剩空焊盘/空脚印
#                                  板子上稳定缺 3 个：K3 3.5mm 音频座 / C4 电解电容 / R3 10k 轴向电阻
#       id 1 = stain    污渍   —— 板面上的液体残留 / 油污 / 指纹油，⌀5~15 mm
#       id 2 = scratch  划痕   —— 板面（丝印/基材）上的机械划伤，长 5~20 mm
#
#   历史：2026-10-24 先用**单类 missing**（方案 A）把链路跑通（28 张 → 110 张，见 test/d33）；
#        2026-10-25 起加 stain / scratch（方案 B），**只在末尾追加**，旧标签 id 不变。
#
# ===================== 以后再加类怎么加 =====================
#   1) 在下面**追加**新类名 —— 千万不要插到前面，否则 id 全变、已有标签全错位；
#   2) 给新类重新拍图 + 标注（旧标签不用改）；
#   3) 重跑 `python tools/make_yolo_dataset.py ...` 生成新 data.yaml（nc 跟着变）。
#
# 说明：
#   1) 一行一个类名；`#` 开头的行与空行会被工具跳过

#   3) 改了这里必须重跑 tools/make_yolo_dataset.py，否则标签 id 与 names 会错位
